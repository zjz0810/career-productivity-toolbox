# 校招岗位整理器

一个无需后端、打开即用的校园招聘岗位收集、筛选和投递跟踪工具。

## 功能

- 批量粘贴招聘文本并智能拆分岗位
- 按公司、城市、岗位关键词、状态和方向筛选
- 编辑岗位信息，跟踪待筛选、准备投、已投递、面试和 Offer 状态
- 导出 / 导入 JSON，导出 CSV
- 数据保存在浏览器 `localStorage`，无需账号和服务器

## 使用

直接打开 [`index.html`](./index.html) 即可使用。首次打开会加载内置示例，后续岗位数据保存在当前浏览器中。

## 文件

- `index.html`：页面结构
- `style.css`：界面样式
- `app.js`：岗位解析、筛选、状态管理和本地数据逻辑

后续岗位数据、筛选功能和说明只放在本目录内，不影响仓库中的其他工具。
