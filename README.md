# career-productivity-toolbox

个人效率、求职辅助和数据自动化工具箱，按独立目录收纳办公技巧速查、求职题库、CS2 数据工具、校招岗位整理等可插拔小项目。

每个工具都是一个相对独立的模块：可以单独开发、运行、维护、添加或删除，尽量避免模块之间互相干扰。

## 项目索引

- [`office-cheatsheet/`](./office-cheatsheet/)：办公软件操作技巧速查工具
- [`interview-question-bank/`](./interview-question-bank/)：求职与面试题库工具
- [`cs2-data-tools/`](./cs2-data-tools/)：CS2 数据抓取、整理和分析工具
- [`campus-job-tracker/`](./campus-job-tracker/)：校招岗位收集、筛选和跟踪工具

## 模块化约定

每个工具只使用自己的目录，推荐结构如下：

```text
tool-name/
├─ README.md       # 工具说明、运行方式和维护记录
├─ src/            # 源代码
├─ data/           # 仅供本工具使用的数据
├─ tests/          # 测试
└─ ...             # 本工具自己的配置和资源
```

- 新增工具：在仓库根目录新增一个独立文件夹，并补充该工具的 README。
- 删除工具：删除对应文件夹即可，不影响其他工具。
- 工具之间默认不直接导入代码、不共享运行环境、不共用配置文件。
- 只有确认多个工具都需要时，才新增 `shared/`，并保持接口稳定。
- 根目录 README 只维护项目索引，不承载具体工具的实现细节。
